# Монтаж говорящая голова

Все правила монтажа роликов Арона — в этой папке. Начинать с `конвейер_монтажа.md`.

| Файл | Что внутри |
|---|---|
| `конвейер_монтажа.md` | **Главная**: этапы и агенты, все принципы Арона, как разбирать замечания, раскладка папки ролика, план доработок |
| `монтаж.md` | Чистое видео (склейки, дубли, слежение за глазами, звук) и правила вставок (что показывать и как) |
| `безопасная_зона.md` + `.png` | Безопасная зона Reels по схеме Арона, центр внимания — общее для всех агентов |
| `запись_экрана.md` | Как снимать сайты и ChatGPT в Chrome Арона, что не подошло |
| `титры.md` | Субтитры и заголовки: шрифт, время по кадрам, текст по смыслу |
| `словарь_титров.json` | Общий словарь исправлений субтитров (ChatGPT, ё, частые ошибки распознавания) |
| `журнал_правок.md` | Все замечания Арона: симптом → этап → причина в логике → что исправлено |

Где остальное:
- агенты — `.claude/agents/` (`montazhyor`, `rezhisser`, `operator`, `titrovshik`, `sborshchik`, `zritel`) — Claude находит их только там;
- команда — `/montazh` (`.claude/skills/montazh/`);
- инструменты — `montazh.py`, `tools/` (`sborka.py`, `titry.py`, `tools/ekran/`, шрифты).
- Материалы ролика (видео, вставки, финал) — в папке ролика, в `<папка>/монтаж/`, не в git.
