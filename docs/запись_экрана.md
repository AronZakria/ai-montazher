# Запись экрана для роликов

Claude сам проделывает действия на сайте (ChatGPT и т. п.), снимает экран и делает вставку 9:16, где **то, что нужно увидеть, стоит в центре безопасной зоны**. Зона и «центр внимания» — `docs/безопасная_зона.md`.

## Основной способ — Chrome Арона (его аккаунты), 2026-09-28

Действия делает Claude через **Claude в Chrome** (вход в аккаунты уже есть), кадры снимает macOS (`screencapture`), дальше та же камера.

1. **Окно записи** — отдельное окно Chrome **520×960** только с группой вкладок Claude. Узкое специально: ChatGPT перестраивается, текст крупнее относительно колонки (в широкой десктопной вёрстке после вписывания в 9:16 буквы вдвое мельче; масштаб страницы не помогает — колонка растёт вместе с буквами).
   Создать (если закрыто): `osascript` → `make new window`, `set index of <окно> to 1`, потом `tabs_context_mcp(createIfEmpty)` — группа Claude появляется в этом окне; лишнюю пустую вкладку закрыть; `set bounds to {40, 40, 560, 1000}`. Переносить вкладку группы в другое окно нельзя — выпадает из группы, Claude теряет управление.
2. Перед съёмкой (JS через Claude в Chrome): открыть `https://chatgpt.com/?temporary-chat=true`, закрыть окошко «Временный чат» («Продолжить»), **размыть историю чатов** (`nav a[href*="/c/"], nav a[href*="/g/"]` → `filter: blur(8px)`), замерить `innerHeight` и рамку места действия (`getBoundingClientRect`).
3. `python3 tools/ekran/okno.py start <папка>` — окно записи вперёд (**Chrome не рисует закрытые окна** — в скрытом окне страница пустая). Арону в это время мышь и клавиатуру не трогать.
4. После каждого действия — `okno.py shot <папка> <hold> <группа> <innerH> [x y w h]`: кадр окна, обрезка до страницы (без вкладок, адресной строки и полоски «Claude запустил отладку»).
5. `okno.py stop <папка>` — Claude обратно вперёд. `kamera.py <папка> --zona` → вставка.
6. После съёмки стереть набранное, если не просили отправлять. **Отправлять запросы с аккаунта Арона — только по его просьбе на конкретный ролик.**

Нужно на Mac (сделано 2026-09-28): разрешение Claude на запись экрана; Chrome и Claude **не в полноэкранном режиме** (окно с другого рабочего стола macOS не снимает). Экран Арона 1920×1080 (не Retina) → кадры в 1×, при приближении ×1,6 слегка мягкие.

### ChatGPT: что выяснилось на съёмке (2026-09-28)
- «Глубокое исследование» есть только в **обычном** чате (во «Временном» пункта нет) — такой чат остаётся в истории Арона.
- **Результат исследования не попадает в контекст чата**: отчёт живёт в отдельном виджете, и следующий промпт «на основе этого исследования…» ChatGPT не видит («мне нужен сам итог исследования»). Рабочий путь: развернуть виджет (⤢) → выделить отчёт Cmd+A → Cmd+C → вставить в поле (станет вложением «Вставленный Markdown») → дописать второй промпт → отправить.
- ChatGPT показывает рекламу (Pro, Work) — закрывать крестиком, ничего не подключать.
- Claude в Chrome рисует свой курсор и розовое свечение по краям: перед кадром — `hover` в угол (505, 5), края режет `okno.py` (EDGE = 14).

## Живая съёмка экрана телефоном (2026-10-17, «Соцсеть для сообществ»)

Когда Арон снимает экран камерой телефона, а режиссёр оставляет эту съёмку как доказательство (муар и курсор — «экран настоящий»). Образец — `Ролики/2026-10-17_соцсеть_для_сообществ/монтаж/вставки/обсуждения.py` (OpenCV в `.venv`).
- Кадры брать из исходника, а не из итога: какой кадр исходника стоит в кадре итога — сравнением уменьшенных картинок (однозначно, разница < 1 уровня). Итог — тот же кадр плюс одно сжатие.
- Стабилизация — каждый кадр к одному опорному (SIFT, гомография RANSAC 2 px): на муаре не дрожит, центры кружков в пределах 1–1,5 px. Вырез, выпрямление и масштаб — одним перспективным преобразованием.
- После стабилизации экран стоит, а муар ползёт (соседние кадры — до 13 уровней разницы): среднее 5 соседних кадров оставляет муар фактурой, но останавливает рябь; буквы не мылятся.
- Яркость выравнивать по средней яркости фона (без букв); медиана и 95-й процентиль на муаре мерят муар, а не экспозицию.
- Курсор и руку проверять по всем кадрам: курсор может уехать в конце куска — тогда кадры взять зеркально назад (экран после стабилизации неподвижен, подмена не видна).
- Маски (подсветка, затемнение) — по предметам, найденным в опорном кадре по цвету, а не по рамкам «на глаз».
- Проверка — `tools/razmyt` с именами и словами сообщений на кадрах по всей вставке и полный OCR (`swift tools/ocr.swift`): читаться должны только названия, даты, цифры.

## Запасной способ — Playwright (чистый профиль, без аккаунтов)

Общее для обоих способов: `kamera.py` и `zona.py`.

- `node tools/ekran/ekran.mjs <сценарий.json> <папка>` — съёмка. Google Chrome (невидимо, чистый профиль) притворяется iPhone 15 Pro Max → мобильная вёрстка. Скриншот 1290 px на каждое действие + координаты места действия. Формат сценария — в шапке файла.
- `python3 tools/ekran/kamera.py <папка> [--zona]` — вставка `вставка.mp4` 1080×1920, 30 fps. С `--zona` ещё `вставка_зона.mp4` для проверки.
- `tools/ekran/zona.py` — безопасная зона: константы + наложение на кадр.

## Правила кадра (зафиксированы 2026-09-28)

1. **Центр внимания.** Место действия — в центре зоны (540, 860). Глаза зрителя стоят на месте, двигается картинка.
2. **Место действия — понятный блок, а не мелкая кнопка:** панель ввода, шапка, меню. Инструмент сам поднимается от кнопки к блоку шириной ≥ половины экрана. Куда именно нажали, показывает жёлтый «палец».
3. **Крупность — от блока:** он целиком влезает в зону (до 970 px по ширине, у иконок справа — до 850). Приближение не больше ×1,6: сильнее — по краям обрывки слов, непонятно, где мы. Отдаление до ×0,62.
4. **Одна позиция камеры на действие.** Во время ввода текста камера стоит (цель — вся панель), не дёргается за каждой буквой.
5. **Переезд плавный**, 0,55 с, с разгоном и торможением; приближение меняется равномерно.
6. **Узкая вёрстка — для шагов интерфейса** (кнопки, меню): узкое окно 520 px / формат телефона. **Длинный текст** (промпт, письмо) — в десктопной версии, раскрыть, карточкой целиком (`kartochka.py`) — Арон, 2026-09-28.
7. **Ждём по факту, а не паузой:** после нажатия инструмент ждёт, пока открывшийся блок появится и перестанет двигаться (`focusAfter`); после закрытия — шаг `hidden`. Слепые паузы ломали порядок: меню выезжало поверх ввода.
8. **Всплывающие окна (cookie) — закрыть до первого кадра**, «только обязательные».
9. За краем скриншота — цвет фона страницы, без чёрных полей.

## Что не подошло (исследование 2026-09-28)

| Способ | Почему нет |
|---|---|
| Встроенный браузер Claude | скриншоты видит только Claude, файлом не сохранить — годится для разведки кнопок |
| Видеозапись Playwright, screencast Chrome | 430 px в ширину, мыльно |
| Экран целиком без камеры | текст у краёв залезал за зону, место действия внизу — глаза бегают |
| Наезд на саму кнопку ×2 | обрывки слов по краям, потерян контекст |
| Поля вокруг блока в % от ширины | широкая панель ввода уменьшалась, текст мельчал — поля теперь фиксированные, 45 px |

## Ограничения

- Аккаунты — только через Chrome Арона (Claude в Chrome). Claude пароли не вводит.
- Отправлять запросы с аккаунта Арона — только по его просьбе на конкретный ролик.
- Приложения на телефоне (Telegram-бот, Instagram) — снимает Арон с телефона.
- Личные данные (почта, имена, токены) — размыть до вставки.
  - **Исключение (Арон, 2026-10-19):** экран своего сообщества или платформы (Swois, TrueSpace), который Арон сам снял, чтобы показать актив, — показывать как есть, **без размытия**: «можно же было просто без блюра показать экран». Размывать только почту, токены, пароли и чужие переписки вне его сообщества.
- Playwright подключён из кэша npx (путь в `ekran.mjs`); надёжнее поставить в проект.
