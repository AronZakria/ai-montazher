# Монтажёр рилсов на Claude Code

Система, которая монтирует вертикальные ролики (Reels, Shorts, TikTok) из сырых записей «говорящей головы». Вы снимаете несколько дублей на телефон, кладёте их в папку и пишете в Claude Code `/montazh`. Дальше шесть агентов по очереди чистят видео, решают, где нужны вставки, снимают их, делают субтитры и собирают финал. После каждого этапа система останавливается и показывает результат.

Автор — Арон Закрия ([@aironzak](https://instagram.com/aironzak) в Instagram). Это его рабочий монтажёр: правила в `docs/` выросли из правок на реальных роликах.

## Что получается

Папка с пятью дублями по 2–3 минуты превращается в ролик 9:16 на 40–60 секунд:

- из каждого куска текста взят лучший дубль, оговорки, мычание и паузы вырезаны жёстко, склейки идут по звуку и не обрывают слова;
- кадр 1080×1920 следит за глазами, как Motion tracking в CapCut. На смене мысли меняется крупность, поэтому склейка не выглядит прыжком;
- громкость −14 LUFS;
- там, где без картинки непонятно, вставлены записи экрана (сайт, чат с ИИ) или карточки-скриншоты, а личные данные на них размыты;
- субтитры идут по одной фразе точно по кадрам, в начале стоит заголовок-хук. Всё важное — внутри безопасной зоны Reels, где его не закроют интерфейс и подпись.

## Требования

- macOS на Apple Silicon (M1 и новее). Распознавание лица, глаз и текста работает на встроенном в систему Vision, расшифровка — на mlx-whisper;
- Xcode Command Line Tools (`xcode-select --install`), нужен `swiftc`;
- ffmpeg с libx264 (`brew install ffmpeg`);
- Python 3.10+;
- [Claude Code](https://claude.com/claude-code) — для конвейера агентов;
- для записи экрана (этап `operator`): Node.js, Playwright (`npm i playwright`) и Google Chrome.

## Установка

```sh
git clone <адрес репозитория> reels-montazher && cd reels-montazher
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
tools/build.sh          # собирает face, eyes, gaze, razmyt, okna из .swift
```

При первой расшифровке mlx-whisper сам скачает модель `whisper-large-v3-turbo` (около 1,6 ГБ).

## Как пользоваться

**Через Claude Code.** Положите дубли (`.mov`/`.mp4`) в отдельную папку, откройте этот репозиторий в Claude Code и напишите:

```
/montazh ~/Desktop/мой_ролик/
```

Все рабочие файлы этапов появятся в `~/Desktop/мой_ролик/монтаж/`. После каждого этапа ответьте «дальше» или опишите правку. Правки разбираются до причины и записываются в `docs/журнал_правок.md`.

**Вручную, без агентов:**

```sh
.venv/bin/python montazh.py ~/Desktop/мой_ролик transcribe   # слова по времени → монтаж/words.json и черновик plan.json
# поправить монтаж/plan.json: какие куски каких дублей брать
.venv/bin/python montazh.py ~/Desktop/мой_ролик render       # → монтаж/итог.mp4 + склейки.txt
.venv/bin/python montazh.py ~/Desktop/мой_ролик slova        # слова итога → итог_слова.json
.venv/bin/python tools/titry.py ~/Desktop/мой_ролик          # титры.json → монтаж/титры.mov
.venv/bin/python tools/sborka.py ~/Desktop/мой_ролик --zona  # сборка.json → монтаж/финал.mp4
```

Все ключи плана описаны в начале `montazh.py`, а правила, по которым агенты принимают решения, лежат в `docs/`.

С ChatGPT или Codex агентов `.claude/` нет, но скрипты и правила те же. Дайте модели прочитать `docs/конвейер_монтажа.md` и файл нужного агента и ведите этапы по очереди.

## Форматы

- **Говорящая голова** — основной формат. Кадр следит за глазами, на смене мысли меняется крупность, вставки на весь экран идут там, где без них непонятно. Субтитры набраны Montserrat. Правила — `docs/монтаж.md`, `docs/титры.md`.
- **Япинг** — человек говорит в фронтальную камеру без единой паузы, всё ускорено минимум в 1,1 раза, кадр неподвижный (`"track": false`). Заголовок и субтитры набраны тонким шрифтом с засечками и стоят рядом с лицом (`"layout": "yaping"` в `титры.json`). Мерки формата — `docs/япинг.md`.
- Пробные форматы, автор их ещё не утвердил: **интервью** (запись звонка — `"format": "interview"` в плане) и **подкаст «квадрат»** (`primery/kvadrat.py`).

## Конвейер агентов

| # | Агент | Что делает | Результат |
|---|---|---|---|
| 1 | `montazhyor` | Выбирает лучшие дубли, режет паузы и мычание, кадрирует 9:16 по глазам, выравнивает громкость | `итог.mp4` |
| 2 | `rezhisser` | Смотрит итог и решает, где оставить лицо, а где дать вставку, что показать и что снять | `монтажный_лист.md` |

| 4 | `titrovshik` | Делает субтитры по кадрам и заголовок-хук в безопасной зоне | `титры.mov` |
| 5 | `sborshchik` | Накладывает вставки и титры точно по секундам листа, проверяет кадры | `финал.mp4` |
| 6 | `zritel` | Смотрит финал 10 кадров в секунду глазами человека, который листает ленту, и ищет мельтешение, мелкий текст, пустые кадры | отчёт с секундами |

Дирижёр — команда `/montazh` (`.claude/skills/montazh/SKILL.md`). Карта конвейера — `docs/конвейер_монтажа.md`.

## Что где лежит

```
montazh.py            монтаж: расшифровка, склейки, кадр по глазам, громкость
tools/titry.py        слой субтитров и заголовков (прозрачный .mov)
tools/sborka.py       финальная сборка: итог + вставки + титры
tools/*.swift         лицо, глаза, взгляд, поиск слов и OCR на macOS Vision
tools/ekran/          запись сайтов в формате телефона, карточки, безопасная зона
tools/fonts/          Montserrat (OFL)
docs/                 правила монтажа, титров, безопасной зоны, журнал правок
primery/              образцы разовых скриптов: проверка финала по всем кадрам, сборка «квадрата»
.claude/              агенты и команда /montazh для Claude Code
```

В правилах встречаются ссылки на `Ролики/…`. Это ролики из рабочей папки автора, на которых появилось правило, и в репозиторий они не входят.
